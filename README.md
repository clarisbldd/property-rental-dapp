# Property Rental DApp

A decentralized property rental application developed to manage property listings, users, and rental transactions using blockchain-based smart contracts.

## Overview

This project is a web-based decentralized application (DApp) that combines PHP-based web functionality with blockchain smart contracts for property rental management.

The application includes functionality for managing properties, users, and rental transactions, with the smart contract implemented using Solidity and managed through the Truffle development framework.

## Features

- Property management
- User management
- Property rental transactions
- Smart contract integration
- Blockchain-based rental logic
- Property listing
- User listing
- Smart contract migration and testing

## Technologies

- PHP
- MySQL
- Solidity
- JavaScript
- Truffle
- Ganache
- HTML
- CSS
- Blockchain / Smart Contracts
